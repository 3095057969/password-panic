# Password Panic V2.0

Password Panic `2.0.0` 是一个围绕 21 条荒诞密码规则展开的单页浏览器游戏，包含验证码、压力阀与骑士抓虫三个互动关卡。

## 主要更新

- 存档升级为 schema V2，提供 V1 显式迁移、严格类型校验、损坏存档备份和未来版本保护。
- 修正胜利判定：必须重新计算全部 21 条规则，持久化的假胜利不会再锁死页面。
- 为延迟回调、聚焦、互动定时器和胜利弹窗增加 session/generation 隔离。
- 修复 IME 合成态 Enter、140 Unicode 码点截断和孤立代理项处理。
- `localStorage` 保存失败时持续显示可访问提示，并在后续保存成功后恢复状态。
- 统一验证码大小写文案、减少动效、回归公告优先级、Escape 关闭胜利弹窗、焦点恢复和分享隐私。
- 整理静态资源路径、PRD V1/V2、评审报告与自动化测试。

## 测试结果

在 Windows 10 `10.0.19045`、Node.js `v24.14.0`、Microsoft Edge `155.0.4283.62` 环境执行 `npm run test:all`：

- 规则与状态契约测试：17/17 通过。
- Edge 浏览器 E2E：17/17 通过。
- 合计：34/34 通过。
- 同步 input handler：p50 `0.10ms`，p95 `0.40ms`。
- 测试日志和详细报告随 Release 附件提供。

## 验证边界

本次 Release 已完成 Edge 桌面环境自动化验证，但未完成 Chrome、Firefox、Safari/WebKit、Android/iOS 真机、真实中文/日文 IME、屏幕阅读器和 200% 缩放验收；性能数据只覆盖同步事件处理，不等同于完整帧级性能门禁。因此，本 Release 不构成全平台兼容性或完整 WCAG 合规声明。
